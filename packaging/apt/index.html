Tributary

live multitrack recording console

A single tribd daemon records every channel while you mix live in a hardware-style web console. Linux, amd64 + arm64, MIT licensed.

Apt repository

This site is a signed apt repository — add it once and upgrades arrive with apt upgrade. Debian 12+ / Ubuntu 22.04+, amd64 and arm64: 

curl -fsSL https://adajane.github.io/tributary/tributary.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/tributary.gpg
echo "deb [signed-by=/usr/share/keyrings/tributary.gpg] \
  https://adajane.github.io/tributary/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/tributary.list
sudo apt update && sudo apt install tributary

Installs the tribd system service, enabled and started on loopback — open http://127.0.0.1:4600. Repository signing key: tributary.asc.

Raspberry Pi appliance

Stock Raspberry Pi OS Lite (arm64) with Tributary and PipeWire preinstalled — flash a card and boot a Pi 3/4/5/Zero 2 W. It hosts its own Wi-Fi network (Tributary-XXXX, passphrase tributary); join it, or plug in ethernet, and the console is live at http://tributary.local.

  1. Download the latest tributary-<version>-pi.img.xz from the releases page.
  2. Flash it to an SD card (8 GB or larger) with one of the tools below — all of them take the .img.xz as-is, no unpacking needed.
  3. Boot. First boot expands the card and starts the console; recordings land in /home/tributary/projects.
  • Raspberry Pi Imager Recommended — Windows, macOS, Ubuntu. Pick the image via “Use custom”. For the hostname / Wi-Fi / user dialog, launch it as rpi-imager --repo <URL of the release’s …-pi-imager.json>.
  • balenaEtcher Cross-platform GUI flasher: select image, select card, flash.
  • Command line Nothing to install on most Linux systems: 
xz -dc tributary-*-pi.img.xz \
  | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress  # sdX = your card

The appliance trusts its LAN — read Security before putting it on a network you don’t own.

Other formats

Everything below is on the releases page unless noted; full instructions live in the README.

  • .deb (one-off) sudo apt install ./tributary_*.deb — same package, no repository.
  • .rpm Fedora / openSUSE: sudo dnf install ./tributary-*.rpm, then sudo systemctl enable --now tribd (ships preset-disabled).
  • AppImage Single file, any distro — only needs ALSA (libasound2).
  • Tarball Bare tribd binary with license and docs.
  • Docker docker pull ghcr.io/adajane/tributary:latest — multi-arch, on GHCR.
