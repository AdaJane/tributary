Tributary apt repository

Signed packages for Tributary, the live multitrack recording console. Debian 12+/Ubuntu 22.04+, amd64 and arm64:

curl -fsSL https://adajane.github.io/tributary/tributary.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/tributary.gpg
echo "deb [signed-by=/usr/share/keyrings/tributary.gpg] \
  https://adajane.github.io/tributary/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/tributary.list
sudo apt update && sudo apt install tributary

Installs the tribd system service (enabled + started, loopback only) — open http://127.0.0.1:4600. Other formats (.rpm, AppImage, Raspberry Pi image, Docker) live on the releases page.
